## 🔬 Labs Completed

### 1. 🗺️ Zenmap Network Scanning Lab
- Used **Zenmap (GUI for Nmap)** to perform network discovery
- Performed **SYN Stealth Scan**, **OS Detection**, and **Service Version** scans
- Analyzed open ports, running services, and network topology
- Tools: `Zenmap`, `Nmap`

### 2. 📚 CEH Module 1 — Introduction to Ethical Hacking
- Studied the **5 phases** of ethical hacking: Recon → Scanning → Access → Maintain → Cover Tracks
- Documented **types of hackers**, attack classifications, and cyber laws
- Covered **CIA Triad**, threat vectors, and vulnerability concepts

### 3. 📝 CEH Notes — Multi-Domain Study
- Comprehensive notes across CEH domains
- Topics: Footprinting, Enumeration, Vulnerability Scanning, System Hacking
- Includes attack methodologies and defense strategies
